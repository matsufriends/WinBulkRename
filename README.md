# 納品これくたーくん

エクスプローラーでファイルを複数選択 → 右クリック → **「納品これくたーくん」** →
ファイル名を入力 → `名前_01.mb`, `名前_02.mb`, … に一括リネームするツールです。

- Windows 10 / 11 対応、追加ランタイム不要 (.NET Framework 4.8 標準搭載分で動きます)
- 管理者権限不要 (現在のユーザーの右クリックメニューにだけ登録します)
- 拡張子は元ファイルのものをそのまま維持します (`.mb` は `.mb` のまま)
- 連番はゼロ埋め 2 桁。100 個以上選択したときだけ自動で 3 桁以上になります
- 並び順はエクスプローラーと同じ自然順 (`scene 2` → `scene 10`)
- 選択外の既存ファイルを上書きしてしまう場合は実行前に中止します

## 友達への配布手順

1. `dist/NouhinCollector.exe` を渡す
2. ダブルクリックして「登録」を押す
   - 本体が `%LOCALAPPDATA%\NouhinCollector\` にコピーされるので、渡した exe はその後削除して OK
3. 以後はエクスプローラーの右クリックから使える
   - Windows 11 では **「その他のオプションを確認」(Shift+F10)** の中に出ます
4. やめたいときは exe をダブルクリック →「解除」

常駐プロセスはありません。右クリックしたときだけ起動します。

## ビルド

.NET SDK 8 以上が必要です。

```powershell
.\build.ps1
```

`dist\NouhinCollector.exe` が生成されます。

## 仕組みメモ

- エクスプローラーは複数選択時、選択ファイル 1 つにつき exe を 1 回ずつ起動します。
  そのため各プロセスが `%LOCALAPPDATA%\NouhinCollector\pending.txt` に自分のパスを追記し、
  最初に起動したプロセス (Mutex で判定) が追記が止まるまで待ってから全件まとめて 1 つのダイアログを出します。
- レジストリ: `HKCU\Software\Classes\*\shell\NouhinCollector`
